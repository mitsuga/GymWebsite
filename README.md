# 🏋️ FIT LIFE GYM

A responsive Gym Website homepage built using **HTML** and **CSS**.

## 📌 Project Description

FIT LIFE GYM is a simple and attractive homepage designed to promote a fitness centre. The website includes essential sections such as a navigation bar, hero section, about section, services, testimonials, contact form, and footer.

## ✨ Features

- Responsive Navigation Bar
- Hero Section
- About Us
- Services Section
- Client Testimonials
- Contact Form
- Footer
- Mobile Responsive Design
- Clean and Modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📁 Project Structure

```
GymWebsite/
│── index.html
│── style.css
│── README.md
└── images/
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Explore the website.
